# 基于 Lite3 四足机器人的二次开发

> 基于 Lite3 平台，开展 ROS 2 仿真适配、MID-360 环境感知、SLAM 建图与自主导航应用开发。

## 项目简介

本项目以 **Lite3 四足机器人为基础平台**，结合 Livox MID-360 激光雷达、Orange Pi AI Pro 20T 和 ROS 2 Humble，围绕机器人仿真、环境感知、地图构建与导航应用开展二次开发。

**项目重点是 Lite3 平台上的系统适配与应用层开发**：复用官方机器人模型和高层运动接口，将雷达感知、激光惯性里程计、地图构建、路径规划与本体运动连接起来，并针对四足机器人的安装外参、机身及足腿包络、坐标变换和运行状态完善配置、调试与实验流程。

本文件包汇集了相关仿真代码、配置、实验说明、快捷启动脚本，以及截图和演示视频，可用于项目展示、开发参考和实验复现。

### 1. Lite3 模型与仿真控制

- 基于 Lite3 URDF 与模型资源，配置机器人显示和 Gazebo Fortress 仿真场景。
- 围绕四足关节建立控制与反馈链路，支持目标关节位置、实际状态和足端运动的观察。
- 提供实验性运动学步态与慢速三足支撑爬行规划，用于步态相位和抬腿过程研究。
- 补充反馈同步、跟踪误差、时间异常和看门狗等检查。
- 组织环境感知、负载姿态、建图及导航相关仿真实验。

仿真运动学控制用于模型调试和教学研究，其验证范围与实机动态平衡控制分别说明。

### 2. 面向 Lite3 的雷达感知适配

- 配置 MID-360 与 Lite3 机身坐标系之间的安装关系，统一点云、IMU 和机器人坐标表达。
- 整理点云可视化、坐标核查、数据采集与回放流程。
- 根据机身及足腿范围配置自体点过滤，减少机器人自身回波对障碍检测的影响。
- 在点云处理流程中考虑重力方向，区分地面与离地障碍，并显示障碍物包围框。
- 监测点云、IMU、里程计和控制反馈的频率、延迟、断流及时间戳异常。

安装外参、自体点过滤范围与导航足迹分别服务于坐标转换、感知和规划，应按实际设备安装、站姿与负载核对。

### 3. SLAM 建图与数据管理

- 复用 FAST-LIO，以 MID-360 点云和 IMU 建立激光惯性里程计与三维点图链路。
- 结合 slam_toolbox 构建二维占据栅格地图，为后续导航提供地图与位姿关系。
- 组织原遥控器控制下的低速行走和振动工况实验，观察运动对建图的影响。
- 记录轨迹、输入数据健康状态和运行结果，保存 YAML、PGM、PCD 及配套元数据。
- 通过实际重读地图和点云文件检查保存结果，保留不同轮次的实验材料。

该部分的二次开发重点是 Lite3 场景下的数据链路集成、配置适配、实验组织和结果管理；核心 SLAM 算法复用既有组件。

### 4. 导航与 Lite3 官方运动接口对接

- **已有地图单点导航**：加载保存的二维地图，通过 AMCL 定位，再由 Nav2 规划与跟踪目标。
- **目标点规划与在线建图**：在 RViz 选择目标，使用实时 SLAM 地图进行导航并持续建图。
- **自主探索与静态避障**：从空地图开始，结合探索目标选择、障碍点云和代价地图开展探索与避障测量。
- **本体运动对接**：将导航速度请求经过速度平滑器和上层运动桥，交给官方 `MotionSender`，再发送至 Lite3 本体。
- **运行流程整理**：按感知、规划、显示、运动接口及任务执行划分终端，配套启动、检查、停车与保存步骤。

实机运动链沿用 Lite3 原厂步态控制器，应用层负责高层速度与导航任务的衔接。


## 部署与验证说明

**本文件包是二次开发资料与实验成果的汇集，部分功能依赖原板端工作空间。** SLAM 与导航目录主要提供操作说明、截图、视频和入口脚本，文档引用的完整 ROS 包、公共依赖、驱动及运动桥需要在部署环境中具备，不能仅将本压缩包视为完整可独立构建的工程。

## 组件来源与项目定位

本项目的开发建立在 Lite3 平台与 ROS 2 生态组件之上：

- **Lite3 官方模型、运动接口与原厂控制器**：提供机器人基础模型和实机运动能力。
- **Livox 驱动与 SDK**：提供 MID-360 点云和 IMU 数据接入。
- **FAST-LIO、slam_toolbox、Nav2、AMCL**：提供里程计、建图、规划和定位能力。
- **本项目二次开发工作**：面向 Lite3 的仿真与感知适配、SLAM 和导航链路集成、官方运控接口对接，以及配套配置、运行工具和实验资料整理。

第三方组件的版权与许可证以各自源码和声明为准，复用与分发时应保留相应来源和授权信息。
