# 5-3 从空地图自主探索与静态避障测量｜Lite3 实机

本章按本次现场选择，从空地图开始，不继承 5-2 旧图。检查点路径、旧图起点、结果目录、导航目录和探索参数均由命令自动生成或读取，不需要手写坐标、路径或编辑 YAML。每次 A 新建独立目录，保留旧地图。

A 复用 5-2 的雷达、FAST-LIO 和在线 SLAM 建图链，登记为阶段 3；F 运行 5-3 自主探索与静态测量。原 `lite3_lab_5_3 experiment.launch.py` 仍要求上一阶段检查点，因此本流程使用下面的 A 命令，不直接执行该旧入口。无需修改板端程序或重新编译。

所有代码块均在香橙派的 Bash 终端执行，按整段复制。Windows 只通过 MobaXterm SSH/X11 操作。现场包络、扫描和通行空间仍需核对；自动填参数不能代替现场确认。

如果已经启动到 F，正等待 `obstacle_cloud缺失或过期`：先在 B 执行 `ros2 service call /lab42/upper/stop std_srvs/srv/Trigger '{}'` 并确认停车；A/D/E/F 正常且无建图锁存故障时保留，直接新增第 3.1 节 G，然后只重开第 5 节 C，再做第 9 节检查。无需为了补上遗漏的障碍分割而重启 A 或丢弃当前地图。必须同时核对实时消息、分割点数和 RViz 橙色点，不能仅凭节点已启动认定看到了障碍。

## 3.1 G：启动障碍分割，保持真实点云持续发布

空地图建图链只生成雷达原始点云和扫描，不自动启动 3-3 障碍分割；必须补充本节。之前 F 持续提示 `obstacle_cloud缺失或过期` 时，先在 B 执行 `/lab42/upper/stop` 并确认停车。若 A/D/E/F 仍健康，可保留这些进程，新增 G，不必仅为补点云而重建地图。

G 加载第 1 节共用环境后，整段复制。自动读取本轮机身高度与已安装分割参数，地面参考使用 `ground_z_m = -body_height`；它是当前安装配置的参考值，地面质量检查仍保留，不能代替实际站姿高度核对。不改原始点云时间戳、不补空障碍、不放宽缺测检查。

```bash
python3 - <<'PY'
import json
import math
import os
import tempfile
import time
from pathlib import Path
import yaml
import rclpy
from ament_index_python.packages import get_package_share_directory

results = Path.home() / 'catkin_ws_lite3dog/results'
run = Path((results / '5_3_current_run.txt').read_text().strip()).resolve(strict=True)
session = json.loads((run / 'session.json').read_text())
if session.get('stage') != 3 or (run / 'mapping_fault.json').exists():
    raise SystemExit('阶段不匹配或建图故障已锁存，请先检查 A')
# 防止另起第二个发布者，混合两套分割输出。
rclpy.init()
probe = rclpy.create_node('obstacle_publisher_probe')
deadline = time.monotonic() + 2.0
while time.monotonic() < deadline:
    rclpy.spin_once(probe, timeout_sec=0.1)
count = probe.count_publishers('/course/obstacles')
probe.destroy_node()
rclpy.shutdown()
if count:
    raise SystemExit('已有障碍点云发布者；保留其进程并检查输出，不要重复启动 G')
height = float(session['configuration']['body_height'])
if not math.isfinite(height) or height <= 0:
    raise SystemExit('本轮 body_height 无效，不能自动配置地面高度')
share = Path(get_package_share_directory('lite3_lab_3_3'))
data = yaml.safe_load((share / 'config/params.yaml').read_text())
output = Path(tempfile.mkdtemp(prefix='perception_', dir=run))
params = data['/**']['ros__parameters']
params.update(input_topic='/course/points_raw', ground_z_m=-height,
              mode='real', use_sim_time=False, autostart=True, result_dir=str(output))
config = output / 'obstacle_params.yaml'
config.write_text(yaml.safe_dump(data, sort_keys=False))
(run / 'perception_current.txt').write_text(str(output) + '\n')
print('障碍分割参数与证据目录：' + str(output), flush=True)
command = ['ros2', 'run', 'lite3_lab_3_3', 'experiment', '--ros-args',
           '--params-file', str(config)]
os.execvp(command[0], command)
PY
```

G 会订阅 `/course/points_raw`，按采样时间 TF 转换和地面分割，再发布 `/course/points_filtered`、`/course/ground`、`/course/obstacles`。三种输出保留输入采样时间。G 有“本帧不发布”时不能忽略：根据日志检查采样时刻 TF、原始数据和地面点数量；不能用最新 TF 或当前时间替代真实采样时间。

## 9. B：运动前检查，显式 enable/start

先确认障碍点云链，所有参数自动读取。第一个命令应显示恰好一个发布者；第二个应收到一条实时消息头，超时则不要放行：

```bash
ros2 topic info /course/obstacles -v
timeout 8s ros2 topic echo /course/obstacles --once --field header --qos-reliability best_effort --qos-durability volatile
RUN="$(cat "$HOME/catkin_ws_lite3dog/results/5_3_current_run.txt")"
PERCEPTION="$(cat "$RUN/perception_current.txt")"
cat "$PERCEPTION/obstacles.json"
```

## 12. 故障检查与证据

- `mapping_fault.json`：输入时间回退/重复、传感器间隔超过 1 秒、积分异常或 LIO 状态不合理时锁存。不能保存为可续建检查点；必须完整退出并重建，不能仅重开 F、清代价地图或重新 enable。

- prepare-nav 失败：在 B 查看下面的网络、感知健康和延迟文件，先修复 A；增加超时或重启 D 不能补出缺失的里程计。
