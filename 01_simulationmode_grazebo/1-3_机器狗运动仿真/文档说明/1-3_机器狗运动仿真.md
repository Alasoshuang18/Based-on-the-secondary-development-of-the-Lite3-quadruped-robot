# 6-3_机器狗步态仿真

> 章节位置：第六章 机器狗仿真与建模  
> 本节主题：Lite3 固定机身抬脚、自由机身抬脚、四方向单项与连续对角步态验收  
> 前置基础：现有香橙派 ROS 2 Humble / Gazebo Fortress 环境及 Lite3 模型能够加载  
> 更新日期：2026年10月16日；当前控制器版本：v5.3.8

本文合并“步态仿真”和“运动仿真”的操作内容，全部适配现有 Lite3 环境。沿用已有模型、源码、配置和安装位置，不安装其他包，不引入其他机器人模型。

## 1. 内容概述与运行流程

本节按以下顺序验证：

```text
固定机身逐腿抬脚：检查关节、逆解和足端轨迹
        ↓
自由机身逐腿抬脚：检查支撑转移和真实足端离地
        ↓
crawl前进、后退、左转、右转单腿单项：检查方向和停止
        ↓
trot连续前进、后退：检查两组对角腿同步交替
        ↓
trot连续左转、右转：检查实际累计转角与漂移
        ↓
正常停止、方向切换、速度指令超时停止
```

Walk/crawl在此指每次一条腿依次运动；Trot指FL+HR同时摆动、FR+HL同时摆动，两组交替。按对角顺序逐条腿抬起，不能算作对角同步摆腿。

运动通过关节目标、地面碰撞及摩擦产生。观察位移时不要拖动模型，也不要修改Pose冒充行走。固定机身验证通过只证明腿部动作，不代表自由机身已经具备稳定行走能力。

```text

    ↓

```

| 参数 | 用途 | 当前设置 |
| --- | --- | --- |
| max_linear_speed | crawl线速度上限 | 0.003 m/s |
| max_angular_speed | crawl角速度上限 | 0.01 rad/s |
| trot_max_linear_speed | trot线速度上限 | 0.02 m/s |
| trot_max_angular_speed | trot角速度上限 | 0.02 rad/s |
| trot_period / trot_duty | 当前trot候选时序 | 1.0 s / 0.60 |
| trot_step_height | trot计划抬脚高度 | 0.025 m |

## 5. 前进、后退、左右转单项验收

本节保留已验证的crawl单项途径。E保持自由机身、`gait_mode=crawl`，完成第4节抬脚验收。每项开始前都先READY，记录X、Y、Yaw、Z，再发送一次零速度：

```bash
ros2 topic echo /lite3_sim/model_pose --once
ros2 topic pub --once /lite3_sim/cmd_vel geometry_msgs/msg/Twist '{linear: {x: 0.0}, angular: {z: 0.0}}'
```

下列命令一次只执行一个。至少完成HL→FL→HR→FR一轮，再按第6节停止和记录。

### 5.1 前进单项

```bash
ros2 topic pub --rate 20 /lite3_sim/cmd_vel geometry_msgs/msg/Twist '{linear: {x: 0.003}, angular: {z: 0.0}}'
```

起始Yaw约0时，停止后的X应总体增加。历史一次实测X从0.035m到0.090m，净前进约5.5cm；此结果仅代表当次测试。

### 5.2 后退单项

```bash
ros2 topic pub --rate 20 /lite3_sim/cmd_vel geometry_msgs/msg/Twist '{linear: {x: -0.003}, angular: {z: 0.0}}'
```

沿机身后方产生净位移。已经转过向时，不能只以世界X是否减小判断。

### 5.3 左转单项

```bash
ros2 topic pub --rate 20 /lite3_sim/cmd_vel geometry_msgs/msg/Twist '{linear: {x: 0.0}, angular: {z: 0.01}}'
```

俯视为逆时针，小角度测试后停止，Yaw应总体增加。

### 5.4 右转单项

```bash
ros2 topic pub --rate 20 /lite3_sim/cmd_vel geometry_msgs/msg/Twist '{linear: {x: 0.0}, angular: {z: -0.01}}'
```

俯视为顺时针，小角度测试后停止，Yaw应总体减小。每项单独记录起终点，单项通过不等于长时间连续或trot转向通过。

```bash
ros2 topic pub --once /lite3_sim/cmd_vel geometry_msgs/msg/Twist '{linear: {x: 0.0}, angular: {z: 0.0}}'
```

```bash

```

换方向无需回世界原点；记录新的起点，先发零速度，再发新方向。不要把12个关节全部设置为0，Lite3正常站姿不是全零角。不要同时运行E和固定机身演示脚本，也不要在E发布轨迹时手动发布站姿轨迹。

## 7. 单项验收记录与常见现象

| 项目 | 记录内容 | 通过条件 |
| --- | --- | --- |
| 固定抬脚 | 四足峰值、结束状态 | 各腿真实离地后落下，calibration_passed=True |
| 自由抬脚 | 四足峰值、姿态、Z | lift_test=4/4，lift_passed=True，回READY |
| 前进/后退 | 起终点X、Y、Yaw、Z | 沿对应机身方向净移动，正常停止 |
| 左转/右转 | 起终点Yaw与位置 | 转向正确，不持续失控漂移，正常停止 |

| 现象 | 解释与处理 |
| --- | --- |
| READY时四脚高度都约0 | 站立待命；历史抬脚看lift_results_mm |
| publishing持续输出但仍READY | 检查E与F域一致，并在抬脚测试结束后重新发零速度 |
| E关闭后gait_status消失 | 节点已退出，不能靠重开echo恢复 |
| X=-0.00、Pitch约0.01rad | 可能是显示舍入与小姿态偏差，结合趋势判断 |
| sync_holds增加 | 等待同步时保持目标，不等于FAULT；仍需检查反馈年龄 |
| 模型Z明显低于地面、遗留抬腿或倾倒 | 不反复enable；保存现场并重建干净世界 |

## 11. 连续左转、连续右转与90°目标

### 11.1 连续左转

```bash

```

俯视逆时针，D中的`trot_turn_ref`应为正。原地转向`trot_speed_ref`接近0正常，并不表示没有转向请求。

### 11.2 连续右转

左转按第12节停止并回READY，重新记录起点，先发零速度，再执行：

```bash
ros2 topic pub --once /lite3_sim/cmd_vel geometry_msgs/msg/Twist '{linear: {x: 0.0}, angular: {z: 0.0}}'
ros2 topic pub --rate 20 /lite3_sim/cmd_vel geometry_msgs/msg/Twist '{linear: {x: 0.0}, angular: {z: -0.01}}'
```

俯视顺时针，`trot_turn_ref`应为负。左右转共用时序检查，左转出现过的问题不能假定右转没有。

### 11.3 90°如何判断

先短时10个半步核对方向和稳定性，再持续转向直到接近相对起点90°，不以30或40个半步作为90°停止条件。90°约1.571rad；截图Yaw=1.16rad，仅在起始Yaw约0时对应约66.5°，不等于90°。

Yaw通常显示在−π～+π之间。每隔一段记录，按相邻角差展开：

```text
单段转角 = atan2(sin(Yaw后−Yaw前), cos(Yaw后−Yaw前))
累计转角 = 各单段转角相加
```

相邻取样之间实际转角应小于π。左转目标累计+1.571rad，右转−1.571rad。不要把四元数rotation.z当成Yaw。

0.01rad/s请求对应90°名义时间约157秒仿真时间，实际受归中、支撑转移、落脚及真实跟踪影响。不能到157秒就宣布通过。接近目标时按第12节停止，停止过程仍可能有少量转动，最终READY后记录实测角度及误差。

## 12. 连续动作的停止、切换与超时验收

### 12.1 正常停止

F按Ctrl+C结束持续发布，再执行：

```bash
ros2 topic pub --once /lite3_sim/cmd_vel geometry_msgs/msg/Twist '{linear: {x: 0.0}, angular: {z: 0.0}}'
ros2 service call /lite3_sim/stop_gait std_srvs/srv/Trigger '{}'
```

E继续运行，等D回READY、四脚落地，再记录终点。停止请求不等于立即落脚；不能为催停而结束E。FAULT状态则不保证上述请求能够恢复站姿。

### 12.2 切换方向

```text
结束F旧发布 → 零速度与stop_gait → 等READY
→ 记录新起点 → 再发零速度 → 发布新方向
```

不用每次重开A～E、回原点或重新抬脚验收；但只要重启E，就需要重新enable和抬脚验收。前进/后退、左转/右转不直接反向切换。

检查速度发布者：

```bash
ros2 topic info /lite3_sim/cmd_vel --verbose
```

未发布时应为0，测试时只保留1个。不要同时运行键盘和命令行速度发布。

### 12.3 速度超时停止

单独测试，不与正常停止混算：

1. READY后发零速度，再按第9节低速前进。
2. 确认真实运动后，只对F按Ctrl+C。
3. 不补零速度、不调用stop_gait，A～E与Gazebo继续运行。
4. 观察指令超时后完成当前落脚，最终READY。

现有`cmd_timeout=0.5`按墙钟时间判断指令过期，表示开始停止的条件，不保证0.5秒内完成落脚。若还有其他速度发布者，此测试无效。通过后下一次动作仍先零速度再发新命令。

### 13.2 当前频率记录怎么解释

本次配置：controller_manager更新100Hz，PosePublisher 50Hz，IMU 100Hz；`state_publish_rate=30`属于控制器状态话题，不能当作joint_states频率。

```bash
ros2 param get /lite3_sim/lite3_controller gait_mode
ros2 param get /lite3_sim/lite3_controller trot_max_linear_speed
ros2 topic echo /lite3_sim/gait_status std_msgs/msg/String --field data
```

应为 `trot`、`0.02`。初始 `DISARMED` 正常；E 启动后关节轨迹发布者应仅有本控制器 1 个。

**F：使能 → 等 READY → 四腿资格测试。两条服务分开执行。**

```bash
ros2 service call /lite3_sim/enable_gait std_srvs/srv/Trigger '{}'
```

等 D 显示 `READY` 后：

```bash
ros2 service call /lite3_sim/test_foot_lift std_srvs/srv/Trigger '{}'
```

等 `READY`、`lift_test=4/4`、`lift_passed=True`，才进入运动。资格测试是逐腿抬脚，之后 Trot 才是 FL+HR / FR+HL 两腿同时摆动。

**F：先发零速度确认，再任选一项持续发布。四条运动命令不能整段同时执行。**

```bash
ros2 topic pub --once /lite3_sim/cmd_vel geometry_msgs/msg/Twist \
  '{linear: {x: 0.0}, angular: {z: 0.0}}'
```

前进：

```bash
ros2 topic pub --rate 20 /lite3_sim/cmd_vel geometry_msgs/msg/Twist \
  '{linear: {x: 0.02}, angular: {z: 0.0}}'
```

后退：

```bash
ros2 topic pub --rate 20 /lite3_sim/cmd_vel geometry_msgs/msg/Twist \
  '{linear: {x: -0.02}, angular: {z: 0.0}}'
```

左转：

```bash
ros2 topic pub --rate 20 /lite3_sim/cmd_vel geometry_msgs/msg/Twist \
  '{linear: {x: 0.0}, angular: {z: 0.01}}'
```

右转：

```bash
ros2 topic pub --rate 20 /lite3_sim/cmd_vel geometry_msgs/msg/Twist \
  '{linear: {x: 0.0}, angular: {z: -0.01}}'
```

**每一项结束：先 Ctrl+C 停止该速度发布，再执行下列两条，等 READY 后才换下一项。**

```bash
ros2 topic pub --once /lite3_sim/cmd_vel geometry_msgs/msg/Twist \
  '{linear: {x: 0.0}, angular: {z: 0.0}}'
ros2 service call /lite3_sim/stop_gait std_srvs/srv/Trigger '{}'
```

首尾位姿在另一个终端记录：

```bash
ros2 topic echo /lite3_sim/model_pose --once
```

通过：D 显示 `WALKING; mode=trot`、对角组交替、半步计数增加；前后退有对应起始机身朝向的净位移，左右转有相应 Yaw 变化；无 FAULT，正常停止回 READY。转过弯以后，不能只看世界 X 的正负判断前进/后退；90° 应比较展开后的净 Yaw 约 ±1.571 rad，不按半步数判断。

本段是快速单项复验，不替代长时间和 90° 转向验收。不要把 6-4 的支撑衔接修正误认为已写入本节原控制器；带载长测使用 6-4 的专用入口。
